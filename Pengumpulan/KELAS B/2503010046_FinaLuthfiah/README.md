 Soal 1

Soal ini membahas penggunaan struct dan array of struct pada C++. Struct digunakan untuk menyimpan data mahasiswa seperti NIM, nama, semester, dan IPK dalam satu tipe data. Program juga menggunakan perulangan untuk input dan output data mahasiswa.

Selain itu, program melakukan:
-Pencarian IPK tertinggi
-Perhitungan rata-rata IPK
-Pencarian mahasiswa berdasarkan semester

Pembahasan:
Program dimulai dengan deklarasi struct Mahasiswa, lalu membuat array maksimal 5 data. Data mahasiswa diinput menggunakan perulangan for.
Untuk mencari IPK tertinggi digunakan proses perbandingan tiap data mahasiswa. Rata-rata IPK dihitung dari total seluruh IPK dibagi jumlah mahasiswa. Pencarian semester dilakukan dengan mencocokkan semester input dengan data yang ada.

Soal 2

Soal ini membahas implementasi Stack dan Queue tanpa STL menggunakan array statis.
Stack menggunakan konsep LIFO (Last In First Out)
Queue menggunakan konsep FIFO (First In First Out)

Program menggunakan fungsi dasar seperti:
-push / pop pada stack
-enqueue / dequeue pada queue

Pembahasan:
Stack digunakan untuk menyimpan buku yang dikembalikan. Data ditambahkan dengan push() dan dihapus dengan pop().
Queue digunakan untuk antrian peminjaman buku. Data ditambahkan dengan enqueue() dan dihapus dengan dequeue().
Program juga menggunakan fungsi isEmpty() dan isFull() untuk mengecek kondisi penuh atau kosong sehingga program berjalan lebih aman.
